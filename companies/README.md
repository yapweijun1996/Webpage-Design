## Status values

| Status | Meaning |
| --- | --- |
| `planned` | The company folder exists; research has not started. |
| `researching` | Company and industry sources are being reviewed. |
| `designing` | Research is sufficient for the current scope; the design brief is being developed. |
| `building` | The website demo is being implemented or verified. |
| `ready` | The implemented scope passes the root README's quality criteria, with limitations recorded. |

These values describe the current stage. Move back to an earlier stage if new findings require more research or design work.
