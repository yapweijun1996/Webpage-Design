# Immersive Home Design v1

Prepared 2026-10-12. Status: **design preparation complete; not implemented; media not ready; user design acceptance open**.

The user wants video to form the environment of the whole Home page, with integrated navigation, typography and actions. The current framed-image animation was rejected. This package defines a new direction; it does not claim that either published demo has changed.

- [Shared design brief](BRIEF.md): authoritative product, composition, content, media and interaction requirements for both builders.
- [Comparison and acceptance](COMPARISON.md): future review method, failure gates and evidence requirements.
- [Identical future CLI prompt](CLI-HANDOFF.txt): prepared handoff for Codex and Claude; no CLI has been launched for this direction.
- [Desktop and mobile static visuals](visuals/README.md): selected raster concepts, including one phone fin-margin refinement; exact prompts and provenance are retained.

The original brief preparation produced documentation only. The subsequent user request adds two static visual mockups with the built-in image tool. No website source, video, runtime or CLI implementation is created here. The coordinates are design targets; the new mockups illustrate the first-screen direction but do not prove actual viewport behavior or an approved video crop. Existing video trials and all previous implementations remain historical evidence.

The same approved landscape/portrait media and posters must be prepared centrally and frozen before a later authorized paired implementation. Missing media prevents a fair video-integration comparison; it does not prevent reviewing this design plan.

This brief supersedes the Home composition and motion treatment in [motion-v1](../motion-v1/BRIEF.md) and [animation-v1](../animation-v1/INTEGRATION.md) for a future iteration. Existing multi-page destinations, fictional-content limits and the simplified Contact journey remain in force. Historical files are not rewritten.
