# Local Website Output

This folder owns all implementation code, configuration and delivered assets. No dependencies need to be installed to build, check or preview.

```sh
npm run build
npm run check
npm run dev
```

Preview: `http://127.0.0.1:4173/`. The source JSON files are in `content/`; the three additional generated demonstrations are in `fixtures/`. See the [workspace README](../README.md) for exact scope, configuration examples, verification and environment limits.

The copy and supplied AI imagery are fictional. The enquiry route is consistently `#enquiry`, with an explicit unavailable-contact state. No data is sent. Round-2 verification used Chrome for the required layouts, history navigation, keyboard menu, collection details, configuration fixtures and progressive enhancement. See the workspace evidence for exact checks and remaining limits.
